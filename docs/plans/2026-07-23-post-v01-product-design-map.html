Attention statesDesign for the user’s mode, not the feature list.

A supervising developer moves between four modes. The interface should change the amount of information and interruption—not the underlying evidence.

Peripheral mode

Let me stop watching.

The user is doing their real work while agents run in the background. Silence is the default; the system speaks only when the expected value of interruption is high.

Phase 1 exit gate

The user can safely look away.

  • Live opens by default and remains readable during heavy capture.
  • Every interrupt states why it fired and what evidence supports it.
  • Partial capture visibly degrades the claim instead of hiding uncertainty.
  • Feed rows, session rows, and attention actions work by keyboard.
  • Routine completion never becomes notification spam by default.
