## Recommended execution

- Plans 001–004 are independent and may be executed in any order or isolated
  worktrees. Land them as separate reviews; each changes a distinct behavior
  boundary.
- Plan 005 must follow Plan 004. The SSE bootstrap depends on spool/Codex live
  delivery having a correct newline commit boundary; otherwise the higher-level
  handoff can still lose an event before it reaches the hub.
- If only one plan can be executed first, choose Plan 002 because it closes raw
  payload egress and hostile-origin mutation at the tokenless API boundary.
- Plan 001 should be completed before distributing another desktop beta build,
  because current one-click adapter installation can report success without a
  runnable capture command.

## Shared invariants

- Local-only: no backend, account, sync, telemetry, remote binding, or remote
  payload forwarding.
- Capture paths do not depend on the daemon and must not interrupt an agent.
- Preserve the five frozen surfaces in `docs/contracts.md`. These plans either
  enforce existing written behavior or add an explicitly backward-compatible
  stream option.
- Standard library only for new Go code unless a plan is stopped and revised.
- Required completion gate for every plan:
  `gofmt -l .` → `go vet ./...` → `go test ./...`.
- Desktop-touching plans also run `pnpm -C apps/tauri-desktop test` and
  `pnpm -C apps/tauri-desktop build` when stated.

## Findings considered and rejected

- Broad TypeScript/Vite major upgrades: dependency audits were clean and no
  current compatibility/security need justified migration risk.
- Speculative Three.js lazy-loading, DOM virtualization, and TUI cache rewrites:
  no profiling evidence showed they outrank correctness/security work; measure
  before planning.
- Cloud control plane or Rust engine rewrite: project docs explicitly gate or
  defer these directions, and they conflict with the immediate local beta
  priorities.
- Removing repeated frontend tests from the desktop OS matrix: cross-platform
  build/runtime coverage has value and the current suite is small.
