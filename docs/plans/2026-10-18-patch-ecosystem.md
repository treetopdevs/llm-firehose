All counters and replay events concern scoped file observations. No cross-session path merging. Host path strings are observations as stored, not canonical filesystem identities.

Never stringify digest objects or infer paths from summaries. A truncated path remains an observed label; do not claim canonical identity. Group by exact observed path plus worktree_id/cwd/repo_id/repo identity (first available prefixed field); absent workspace marked unknown. No slash/case/relative normalization. Explicit count for file observations without usable path. Distinct event IDs, exclude conflicting duplicate IDs entirely, count duplicates/conflicts/missing IDs. Stable valid time then captured ID; invalid clocks excluded from temporal replay but listed in undated section with receipt access. No source clock duration inference.

Classify each file observation conservatively: payload.phase=start or status=started => attempt; status=error/failed/interrupted or severity=error => failed; status=success/completed => reported-complete; else unknown. Failed wins over start. Completion is source-reported file-tool completion, not verified final file content or successful patch quality. No attempt/end coalescing or double-count as edits: all displayed quantities say observations, with attempt/complete/failure/unknown breakdown. Real existing Score fixture.session.json tests Claude Edit/Write paths; actual Codex normalized fixtures where available prove multi-path changes/digests. Never invent raw adapter fixtures.

No automatic reversion detection: no reliable content before/after or Git proof available. Explicit legend states reversions and net content changes unavailable. Repeated file observations produce denser stems; growth counts observations, not changed lines or quality. Preserve a useful prototype through replay and drilldown without pretending unavailable ghost branches are observed.
