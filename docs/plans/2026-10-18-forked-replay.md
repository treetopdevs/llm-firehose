New app-local key agentfirehose.replay.v1, separate from capture/privacy/spool/exports. Persist user text and reference only: {id,source,sessionId,eventId,title,steps:string[]}; no event payloads, summary/path snapshots, credentials or copied raw capture. Every step is hypothetical with unknown outcome and timing. Max50 branches, title120 chars, max12 steps, each500 chars; nonempty trimmed text, nonempty exact reference IDs max1024. Local IDs crypto.randomUUID. Schema {version:1,branches}. Validate entire decoded document, all required types, strict allowed fields, maxbyte budget512KiB and unique branchIDs; unsupported version/corrupt/oversize read-only and retained. Do not silently discard user data. Storage unavailable write failure must leave edits unsaved and prior document intact. Persistence is best effort, not encrypted, not controlled by capture privacy; disclosure visible. No reset/delete-all action. Individual Delete branch confirmation native UI twice; user deletion authorized by explicitbutton interaction, no silent pruning.

Export types ReplayBranch, ReplayBook; readReplayBook(storage): {book:ReplayBook,token:string|null,writable:boolean,error?:string}; saveReplayBook(storage,expectedToken,book): {ok:boolean,token?:string,error?:string}; Storage seam Pick<Storage,'getItem'|'setItem'>. read errors fallback empty read-only. save validates, compares current raw string to expectedToken immediately before write; conflict returns error and does not replace other document. Re-read user-triggered Refresh notebook enables recovery after conflicts, but must not silently erase unsaved form: ask explicit discard confirmation or keep form and advise copy/reapply. No atomic cross-window guarantee beyond optimistic check; document this limit. Helpers validate/new/edit may be in notebook module as needed but exported types fixed. Must not mutate caller objects.
