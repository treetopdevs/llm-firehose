## User outcome

Airspace gains a Shared recorded files region with file lanes and participant controls. Users can see which sessions in the filtered attention snapshot have recorded the same exact scoped path and inspect the recorded file receipt. This closes the previously deferred shared-file visualization seam. This is historical shared observation, never concurrent editing, physical-file identity, a collision prediction or write conflict.

Group by exact kind/value/path; deduplicate source/session participants; require two distinct participants after filtering. Include only sessions in the currently filtered attention snapshot (before its 20-session pagination). Its source/workspace/text filters determine eligible sessions; the recent-window selector only changes bands, not historical file eligibility. Disclose this. No implied temporal overlap from first/last observation ranges.

## Interaction and scale

Show grouped file lanes, complete wrapped path and scope, participant source/session, observation count and recorded range. Deterministic group order kind/value/path, participant source/session. Flatten participant rows for pagination at 40 per page; repeated lane headings and displayed/total participant and group counts explain partial lanes. All participants remain reachable; no hidden fixed cutoff. Native buttons and semantic headings/list provide keyboard access. Page changes focus a persistent heading. Grouping/filtering remains linear plus sorting over full loaded history; full API array and memory remain unbounded and are disclosed, no fabricated performance claim.

Inspect verifies id/source/session, exact scope kind/value and path membership using the existing recorded-path extraction rules before showing captured JSON. Empty last_event_id disables inspection. Selection uses separate request token/abort and a region owned by shared files. Mode/filters/page/refresh/deactivation/disconnection invalidate selection and obsolete responses. Close restores opener focus if connected, else persistent heading. Errors provide explicit Retry. Failed shared-file refresh retains prior rows prominently marked stale; never present stale data as newly checked. Filters may regroup retained rows but must retain error/retry. Disconnect aborts pending requests and marks retained rows stale; a first load without rows ends idle with an explicit Load and never stays Loading; reconnect alone does not refresh. Activation marks stale after leaving and requires explicit shared refresh. No new persistence, capture/backend/privacy changes, dependencies or external calls.
