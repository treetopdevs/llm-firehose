## Outcome and evidence

Add airspace navigation and Attention Airspace title. Five horizontal bands give a bounded overview of source/session-scoped observations: Request captured, Failure captured, Recent activity, Quiet / unknown, Completion captured. A session marker exposes identity, latest evidence and pending request/failure where available; the latest observation may differ from the event that set the projected state, so nonpending inspection is labelled latest observation; inspect opens full captured JSON and exact source-scoped Score. The visual has a parallel accessible list. This is an observation board, not process monitoring. No inferred runtime, productivity, session termination, conflict prediction or causality.

Use only attention(signal) GET /attention. Never join legacy /sessions (native-ID-only key). Exact identity is JSON tuple(source,id). pending kind failure -> Failure captured; any other pending -> Request captured. Pending remains in its band regardless of age. Without pending: failed -> Failure captured, done -> Completion captured; working with a valid nonfuture event timestamp within selected window -> Recent activity; everything else -> Quiet / unknown. Done includes turn completion, not proof the session ended. Unexpected state and clock uncertainty remain visible. last.source_time ?? last.time defines event recency; never use recent import time as source activity. Label event time versus capture/last_observed_at explicitly; missing source_time means event time, not a claimed source clock. No observation within a selected window is not proof of idleness. Show event-age only for finite nonfuture clocks; otherwise unknown/future.
