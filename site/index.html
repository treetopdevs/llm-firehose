Which agent needs you?

Agent Firehose is a live, structured timeline of what Claude Code, Codex and OpenCode are doing on your machine. Run more agents in parallel than you could track by hand, and still see the one that is blocked.

$brew install treetopdevs/tap/firehose

macOS and Linux. Open source, MIT. Desktop app for macOS

:20? needs you

The session you forgot.

Every live session gets one line: the agent, a sparkline of its events over the last five minutes, and a dwell bar for how long it has been in its current state.

The bar has a hairline at five minutes and is full at ten. A session waiting past the line is the one you forgot. Sessions that need you sort first, longest wait first.

10:05:02≡ the viewer

Three altitudes, one glyph grammar.

Start high, descend into what matters. Scope stays in the header as a breadcrumb, so you always know where you are.

  1. Workspace

    One row per workspace, one column per agent. Each cell is a sparkline, a state glyph and a session count.

    enter on a cell descends

  2. Session

    The live feed, scoped to the cell you picked. Rows print the clock and workspace only when they change, and repeats coalesce into one row with a ×N counter.

    enter on a row descends, esc ascends

  3. Call

    A designed table, not a payload dump. When a source reports both ends of a call, start and end are paired by call id with the duration, then the request and the response as keys and values.

    esc ascends

:41● sources

It reads the agents you already run.

Every source is mapped into one normalized event before it is shown, stored or exported. Capture paths fail silently: a broken hook becomes a warning in the timeline, never an interruption in your session.

SourceDepthHow it is capturedWire it up
Claude Code deep Asynchronous, metadata-only hooks forward through a fail-silent local command. firehose install claude-code
Claude Code OTel supplemental Opt-in loopback request and usage metadata. Identity and content are discarded. firehose install claude-otel
Codex deep A crash-safe, durable tail of ~/.codex/sessions, plus optional lifecycle and tool hooks. firehose install codex
OpenCode deep A plugin forwards high-signal bus events and bounded drift warnings. firehose install opencode
Antigravity deep Three post-only hooks. Firehose never sits in a permission decision. firehose install antigravity
Any process shallow A process watcher emits start and stop for known agent binaries. nothing to install
Anything else generic Pipe NDJSON in, or emit a single event from a script. firehose ingest or firehose emit

10:06:17■ on your machine

Nothing leaves the machine.

No backend, no accounts, no sync, no telemetry. The capture engine, the history and the viewer all run on-device.

Where history lives
Append-only daily files in ~/.agentfirehose/spool/. Delete the directory to delete your history.
What listens
An optional daemon on 127.0.0.1:4517, loopback only. Capture never depends on it being up.
What gets stored
Only what the privacy mode allows. Redaction runs before anything is written, so the spool never holds more.

One event, three privacy modes

Modes govern captured history: the spool, the live stream and exports. Payload values and paths are reduced; the one-line summary is kept in every mode. Switch with firehose privacy minimal, and it applies live.

:58$ install

Three commands to a live view.

  1. Install

    $brew install treetopdevs/tap/firehose

    Installs firehose and the firehosed daemon on macOS or Linux. To keep the daemon running at login, add brew services start firehose.

  2. Wire up an agent

    $firehose install claude-code

    Merges hooks into ~/.claude/settings.json and backs the file up first. Repeat with codex, opencode or antigravity, then run firehose doctor to check the wiring.

  3. Watch

    $firehose

    Opens the live view. Press ? for the legend, space to pause, e to export exactly what you are looking at.

Prefer a window?

The desktop app for macOS wraps the same engine: an attention inbox, session lanes on a wall-clock axis, a workspace graph, and a doctor with one-click adapter install. It starts its own daemon only when you are not already running one.

$brew install --cask treetopdevs/tap/agent-firehose

From source

Go, Bubble Tea and the standard library. Clone the repository, run go build ./cmd/firehose, and put the binary on your PATH.
